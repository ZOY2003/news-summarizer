01做了什麼

新聞常常很長，快速掌握重點不容易。這支 Python 程式讀取多篇新聞，呼叫 Google Gemini API，並使用 結構化輸出（Structured Output）：以 Pydantic 定義固定欄位，讓模型一定回傳格式正確的 JSON，而不是一段自由文字。結果存成 results.json，再由本頁讀取呈現。

① 輸入data/news.json
多篇新聞標題與內文
② 呼叫 LLMGemini API
附上 Pydantic schema
③ 輸出site/results.json
格式固定的結構化資料
④ 發布GitHub Actions
自動部署到 Pages

02怎麼執行

# 1. 安裝套件（使用 uv）
uv sync

# 2. 設定金鑰：複製範例檔後填入自己的 Gemini API key
cp .env.example .env

# 3. 執行摘要程式，結果會寫入 site/results.json
uv run main.py

# 4. commit 並 push，GitHub Actions 會自動部署本頁
git add . && git commit -m "更新摘要結果" && git push

金鑰只存在 .env，已列入 .gitignore，不會上傳到 GitHub。
